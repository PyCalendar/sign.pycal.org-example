# KI-Richtlinie (Beispiel)

Dies ist eine Test-Vereinbarung von [sign.pycal.org](https://sign.pycal.org). Sie ist
der KI-Richtlinie des Python Calendaring Ecosystem nachempfunden, ist aber nicht diese
Richtlinie. Diese Übersetzung dient dem Lesen; verbindlich ist das englische Original.

Mit meiner Unterschrift stimme ich, die mitwirkende Person, für jeden Pull Request,
den ich in einem Repository öffne, das diese Vereinbarung verlangt, Folgendem zu:

1. **Ich bin verantwortlich.** Ich habe jede Änderung, die ich einreiche, geprüft und
   verstanden, ob ich sie selbst oder mit Hilfe eines KI-Werkzeugs geschrieben habe.
2. **Ich lege KI-Hilfe offen.** Wenn ein KI-Werkzeug einen wesentlichen Teil einer
   Änderung erzeugt hat, sage ich das im Pull Request und nenne das Werkzeug.
3. **Ich zeichne die Prompts auf.** Wo das Repository die Prompts von KI-Werkzeugen
   aufzeichnet, etwa mit ai-prompt-auto-commit, lasse ich diese Aufzeichnung aktiv.
4. **Ich achte Lizenzen.** Ich reiche keinen erzeugten Code oder Text ein, von dem ich
   Grund zur Annahme habe, dass er Werke unter einer unverträglichen Lizenz kopiert.
5. **Ich teste.** Änderungen kommen mit Tests, und ich habe sie ausgeführt.
6. **Geheimnisse bleiben aus den Prompts.** Keine Passwörter, Tokens oder Schlüssel,
   weder meine noch die anderer.

Maintainer dürfen Pull Requests schließen, die dieser Richtlinie nicht folgen.
