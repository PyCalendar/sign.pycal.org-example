# AI Policy (example)

This is a test agreement of [ai.pycal.org](https://ai.pycal.org). It is modelled
on the AI policy of the Python Calendaring Ecosystem, but it is not that policy.

By signing, I, the contributor, agree to the following for every pull request I
open in a repository that asks for this agreement:

1. **I am responsible.** I have reviewed and understood every change I submit,
   whether I wrote it myself or with the help of an AI tool.
2. **I disclose AI assistance.** If an AI tool generated a meaningful part of a
   change, I say so in the pull request and name the tool.
3. **I record the prompts.** Where the repository records the prompts of AI
   tools, for example with ai-prompt-auto-commit, I keep that recording active.
4. **I respect licenses.** I do not submit generated code or text that I have
   reason to believe copies work under an incompatible license.
5. **I test.** Changes come with tests, and I have run them.

Maintainers may close pull requests that do not follow this policy.
