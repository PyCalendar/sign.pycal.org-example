# sign.pycal.org-example

This is an example repository for [sign.pycal.org](https://sign.pycal.org).

Create a pull request here to try it out.

The agreements in `agreements/` have translations next to them, such as
`agreements/cla.de.md` (German) and `agreements/cla.es.md` (Spanish). People who
use the site in German or Spanish read the translation and sign the English
original.
