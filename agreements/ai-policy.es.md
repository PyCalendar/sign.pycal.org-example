# Política de IA (ejemplo)

Este es un acuerdo de prueba de [sign.pycal.org](https://sign.pycal.org). Se inspira
en la política de IA del Python Calendaring Ecosystem, pero no es esa política. Esta
traducción sirve para leer; el original en inglés es el vinculante.

Al firmar, yo, quien contribuye, acepto lo siguiente para cada pull request que abra
en un repositorio que pida este acuerdo:

1. **Soy responsable.** He revisado y entendido cada cambio que envío, lo haya escrito
   yo o con la ayuda de una herramienta de IA.
2. **Declaro la ayuda de IA.** Si una herramienta de IA generó una parte importante de
   un cambio, lo digo en la pull request y nombro la herramienta.
3. **Registro los prompts.** Donde el repositorio registra los prompts de herramientas
   de IA, por ejemplo con ai-prompt-auto-commit, mantengo ese registro activo.
4. **Respeto las licencias.** No envío código o texto generado si tengo motivos para
   creer que copia obras bajo una licencia incompatible.
5. **Hago pruebas.** Los cambios vienen con pruebas, y las he ejecutado.

Quienes mantienen el proyecto pueden cerrar pull requests que no sigan esta política.
